# Specification: IEEEtran + 2020 A–Z SOP Master Rules (`ieee-a2z-spec`)

## 1. LaTeX Format & Packages
- Document class: `\documentclass[conference]{IEEEtran}`
- Required packages: `cite`, `amsmath,amssymb,amsfonts`, `graphicx`, `booktabs`, `algorithm`, `algpseudocode`, `url`.
- All prose special characters must be escaped (`\_`, `\%`, `\&`, `\#`, `\$`).
- All `\cite{...}` keys must match `\begin{thebibliography}{00}` 1-to-1.

## 2. 2020 A–Z SOP Complete Mapping
- **Abstract (`A–F`)**: `[A]` Attention Getter, `[B]` But, `[C]` Cure, `[D]` Development, `[E]` Experiments, `[F]` Findings (expected targets).
- **I. Introduction (`G–L`)**: `[G]` General, `[H]` However, `[I]` In literature, `[J]` Judgement, `[K]` Keypoint, `[L]` List the organization.
- **II. Related Work (`M–O`)**: `[M]` Methods (old to new), `[N]` New proposed, `[O]` Organize (4×5 SWOT `table*`).
- **III. Proposed Scheme (`PA–PM`)**: `[PA]` Aim, `[PB]` Based on, `[PC]` Cure/Cause, `[PD]` Design/Paradigm shift, `[PE]` Paper elements (M1–M8), `[PF]` Formulation, `[PG]` Graph, `[PH]` How, `[PI]` Implementation/Algorithm 1, `[PJ]` Jump to an example, `[PK]` Key points contribution, `[PL]` Later simulation, `[PM]` Math proof.
- **IV. Simulation (`Q–V`)**: `[Q]` Quality & Quantity, `[R]` Related methods, `[S]` Simulation Setup, `[T]` Tuning parameters, `[U]` Useful results (expected targets), `[V]` Verify effectiveness.
- **V. Conclusion (`W–Z`)**: `[W]` What proposed, `[X]` eXcel, `[Y]` Yields, `[Z]` Zen.

## 3. Academic Integrity Invariant
No fabricated experimental data is permitted; all unexecuted empirical metrics remain explicitly labeled as planned protocols or expected targets.
