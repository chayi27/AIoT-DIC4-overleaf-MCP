# Project Specification: DietSense — ICEIB IEEE Conference Paper (2020 A–Z Split)

## 1. Project Background & Core Positioning
**DietSense (營養特工)** is a conversational Domain AI Agent for localized Taiwanese daily calorie and nutrition tracking, built on the core architectural principle:
> **LLM for Understanding & Orchestration; Domain Engine for Computation.**
